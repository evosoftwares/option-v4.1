# 📱 GUIA COMPLETO DE INSTALAÇÃO E CONFIGURAÇÃO - APP OPTION

Bem-vindo(a) ao Option! 🎉 Este guia vai te ajudar a instalar e configurar o aplicativo do zero, seja você um passageiro ou motorista. Vamos começar!

---

## 📋 PRÉ-REQUISITOS DO SISTEMA

### 📱 Versões Mínimas do Sistema
- **Android**: 7.0 (Nougat) ou superior
- **iOS**: 12.0 ou superior

### 🖥️ Requisitos de Hardware
- **Memória RAM**: Mínimo 2GB (recomendado 4GB+)
- **Armazenamento**: 150MB livres para instalação
- **Conexão**: Internet 3G/4G/5G ou Wi-Fi
- **GPS**: Chip GPS ativo (obrigatório para funcionamento)

### 🔐 Permissões Necessárias
- Localização (sempre ativa)
- Câmera (para foto de perfil e documentos)
- Galeria de fotos
- Microfone (para chamadas de emergência)
- Notificações push
- Armazenamento (Android)

### 💳 CONFIGURAÇÃO DE MÉTODOS DE PAGAMENTO

**Para Passageiros:**

**Cartão de Crédito/Débito:**
1. Vá para "Pagamentos" no menu
2. Toque em "Adicionar Cartão"
3. Digite os dados do cartão:
   ```
   Número do cartão: [16 dígitos]
   Validade: [MM/AA]
   CVV: [3 dígitos]
   Nome no cartão: [como aparece]
   ```
4. Toque em "Salvar"

**PIX:**
1. Toque em "PIX"
2. Escaneie o QR code ou cole a chave
3. Confirme o cadastro

**Saldo em Carteira:**
1. Toque em "Adicionar Saldo"
2. Escolha o valor
3. Selecione o método de pagamento
4. Confirme a recarga

## 🔒 DICAS DE SEGURANÇA BÁSICAS

### 📱 Segurança do App
- **Sempre verifique** o motorista e veículo antes de entrar
- **Compartilhe sua viagem** com alguém de confiança
- **Use o botão de emergência** se necessário
- **Nunca compartilhe** sua senha com ninguém

### 🚗 Segurança na Viagem
- **Confirme a placa** antes de entrar no veículo
- **Sente no banco de trás** para mais segurança
- **Use o cinto de segurança** sempre
- **Evite distrações** durante a viagem

### 💰 Segurança Financeira
- **Verifique o valor** antes de confirmar pagamento
- **Guarde os comprovantes** de pagamento
- **Reporte cobranças suspeitas** imediatamente
- **Nunca faça pagamentos fora do app**
