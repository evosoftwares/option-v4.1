# Guia de Áreas Proibidas para Motoristas

## Como Acessar as Configurações de Áreas Proibidas

### Passo 1: Acesse o Menu do Motorista
1. Abra o aplicativo Option
2. Faça login com sua conta de motorista
3. Na tela principal, toque no **ícone de menu** (três linhas) no canto superior esquerdo
4. Você será direcionado para o **Menu do Motorista**

### Passo 2: Encontre as Opções de Áreas Proibidas
No Menu do Motorista, você encontrará **três opções relacionadas às áreas de atuação**:

#### 1. **Zonas Excluídas** (Ícone 🚫)
- **Caminho**: Menu do Motorista → Trabalho → Zonas excluídas
- **Função**: Defina áreas específicas onde você **não quer aceitar corridas**
- **Como funciona**: Desenhe polígonos ou marque círculos no mapa para criar zonas de exclusão

#### 2. **Bairros Indisponíveis** (Ícone 📍)
- **Caminho**: Menu do Motorista → Trabalho → Bairros indisponíveis
- **Função**: Selecione bairros específicos onde você **não está disponível**
- **Como funciona**: Lista de bairros para marcar como indisponíveis

#### 3. **Áreas de Atuação** (Ícone 🗺️)
- **Caminho**: Menu do Motorista → Trabalho → Áreas de atuação
- **Função**: Defina suas **áreas preferenciais** de trabalho
- **Como funciona**: Marque as regiões onde você **deseja aceitar corridas**

## Como Configurar Áreas Proibidas

### Configurando Zonas Excluídas
1. Toque em **"Zonas excluídas"**
2. Toque no botão **"+"** para adicionar nova zona
3. **Desenhe no mapa** a área que deseja excluir:
   - **Toque e arraste** para criar um polígono
   - **Use o círculo** para definir uma área circular
4. **Nomeie a zona** (ex: "Centro - evitar trânsito")
5. **Salve** a configuração

### Configurando Bairros Indisponíveis
1. Toque em **"Bairros indisponíveis"**
2. **Procure ou role** a lista de bairros
3. **Marque os bairros** onde não quer aceitar corridas
4. **Confirme** sua seleção

### Configurando Áreas de Atuação
1. Toque em **"Áreas de atuação"**
2. **Marque as regiões** onde deseja trabalhar
3. **Desmarque** as áreas que não deseja atender
4. **Salve** suas preferências

## Dicas Importantes

### ✅ **Funcionalidades Disponíveis**
- **Múltiplas zonas**: Você pode criar várias zonas excluídas
- **Edição fácil**: Toque em qualquer zona para editar ou excluir
- **Visualização clara**: As zonas aparecem destacadas no mapa
- **Ativação/desativação**: Você pode ativar/desativar zonas sem excluí-las

### ⚠️ **Limitações**
- **Zonas ativas**: As zonas excluídas afetam apenas corridas **novas**
- **Corridas em andamento**: Não afetam corridas já aceitas
- **Área de busca**: Você ainda aparece para corridas fora das zonas excluídas

### 🔄 **Gerenciamento**
- **Visualizar todas**: Veja todas suas zonas excluídas em uma lista
- **Editar**: Toque em uma zona para ajustar o tamanho ou localização
- **Excluir**: Deslize para excluir uma zona ou use o botão de exclusão
- **Histórico**: Veja quando cada zona foi criada ou modificada

## Solução de Problemas

### **Não consigo encontrar as opções**
- **Verifique**: Você está logado como **motorista** (não passageiro)
- **Atualize**: Feche e abra o app novamente
- **Reinstale**: Se o problema persistir, reinstale o aplicativo

### **As zonas não estão funcionando**
- **Verifique conexão**: Precisa de internet para aplicar as zonas
- **Reinicie o app**: Feche completamente e abra novamente
- **Verifique status**: Confirme se está online e disponível

### **Precisa de ajuda**
- **Suporte**: Use a opção "Ajuda" no Menu do Motorista
- **WhatsApp**: Envie mensagem para o suporte através do app
